# 食物

> 在无法依赖正常食品供应时，获得、保存、处理并持续获得食物的能力。

食物解决的不只是“今天吃什么”。

当商店、物流和正常供应持续中断时，需要逐渐回答：

* 手上的食物还能吃多久？
* 哪些已经不能吃了？
* 怎样在条件变差的情况下把它做熟、做得安全？
* 怎样让有限的食物撑得更久？
* 吃完以后从哪里继续获得？
* 怎样从一次性的储备，变成可以持续产出的来源？

## Level 划分

| Level | 能力目标 | 核心知识 |
|---|---|---|
| L1 · 基本进食 | 用手上已有的食物，安全地吃、判断营养缺口并合理地分，尽量撑得更久 | 10 |
| L2 · 保存与管理 | 用储存、密封、低温、干燥等手段延长已有食物的可用时间 | 8 |
| L3 · 获取与替代 | 主动在环境中寻找、采集、捕获食物，并做基础处理 | 5 |
| L4 · 持续食物来源 | 建立可以持续产出的食物来源（尚未展开） | 0 |

Level 的判断标准不是“知识难不难”，而是**它在能力发展中处于什么位置**：

* L1 的每个节点，都是食物供应中断后当天就能用、并且不需要额外材料的；
* L2 的节点需要一定的容器、材料、能源或条件；
* L3 的节点需要主动外出获取；
* L4 才是自己建立食物生产。

## L1 · 基本进食

### 能力目标

能够利用当前能够获得的食物，安全地维持基本进食。

L1 首先解决：

> **有东西的时候，能够安全地吃；东西不多的时候，知道先吃什么、怎么分。**

首先要能够：

* 知道手上有什么、大概还能撑多久
* 判断哪些食物已经不能吃
* 在条件变差时把食物做熟、做得安全
* 判断现有食物的主要能量来源和明显营养缺口
* 把有限的食物分配得合理
* 减少因为食物引起的疾病和浪费

* [[清点现有食物]]

* [[可食与不可食]]
* [[食物安全]]
* [[基本烹饪]]

* [[食物分配]]
* [[避免食物浪费]]
* [[饮食与饮水]]

### 不够怎么办

当手上的食物明显不够，或现有条件已经无法保证安全时，进入 L2。

## L2 · 保存与管理

### 能力目标

当新的食物无法稳定获得时，能够延长已有食物的可用时间，并把食物管理变成一个有计划的过程。

核心转变：

> 从“吃掉食物”进入“管理食物”。

* [[食物储存]]

* [[低温保存]]
* [[食物脱水]]
* [[食物轮换]]
* [[长期食物计划]]

### 不够怎么办

当现有储备结构已经建立起来、但总量仍然不够时，进入 L3，开始主动向外获取。

## L3 · 获取与替代

### 能力目标

现有储备不足时，能够通过环境、已有资源和简单工具获得更多食物，并对这些食物做基础处理。

### 核心知识

* [[野外可获得食物]]
* [[安全识别食物]]
* [[采集]]
* [[捕获]]
* [[基础加工]]

这里开始明显依赖：

* [[水]]
* [[火]]
* [[工具]]
* [[卫生]]

因此这些知识应通过 Wikilink 连接，而不是重复建立相同内容。

### 不够怎么办

当储备和野外获取都已经跟不上消耗，唯一可持续的出路是自己生产——这件事已拆成两个独立能力：地里种出来的归 [[种植]]，动物、加工、整年的来源规划归 [[生产]]。

## L4 · 持续食物来源（已由 [[种植]] 与 [[生产]] 承接）

### 能力目标

在长期供应中断的情况下，建立基本、可重复的食物来源。

核心转变：

> 从"寻找食物"进入"生产食物"。

食物章节到获取、保存和基础加工为止。往后的种植和生产各自有完整索引：

| 内容 | 在哪 |

| [[基础种植]]、[[种子保存]]、[[土壤基础]]、[[肥料与养分]]、[[简单灌溉]] | [[种植]] 的 L1 / L2 |
| [[季节性食物]] | [[种植]] 的 L3（错峰排种） |

| 越冬前把食物、燃料、保暖一起备齐 | 整合主题 [[越冬]] |

怎么用：手上还有的吃完之前，先看 [[食物来源规划]] 定一年吃什么、再看 [[基础种植]] 与 [[基础养殖]] 动手；两处正文里引用的水、肥、储存、工具节点都是实节点，本页不再复述。

## 继续探索

食物能力的主线是：

> **安全进食 → 保存已有食物 → 主动获取 → 持续生产**

农业体系、大规模畜牧、工业食品生产等更高复杂度内容可以继续向后发展，但不作为第一阶段的核心入口。
