# 热量与营养管理

> 食物不只要能填肚子，还要让人维持体力。先看总量够不够，再找食物结构里最明显的缺口。

## 立即知道

判断现有食物时，按这个顺序：

1. **先看能量够不够**：主食和油脂决定一批食物大致能撑多久。
2. **再看蛋白质和脂肪有没有长期缺口**：只吃主食，短期能饱，身体状态仍会逐渐变差。
3. **再看食物是否过于单一**：长期缺少豆类、蛋奶肉鱼、蔬菜水果等不同类别，容易出现微量营养缺口。
4. **最后才微调口味和餐次**：先保住总量与结构，不追求理想食谱。

这不是精确配餐。年龄、体型、活动量、温度、疾病和恢复状态都会改变需要量；不要把一个平均数字当作所有人的固定配额。

## 怎么做

### 准备一张清单

需要：

* [[清点现有食物]] 得到的种类、数量和状态；
* 包装上的每份重量、能量和营养成分标签；
* 纸笔或其他不会丢失的记录方式；
* 厨房秤或带刻度容器（有就用，没有也可以按包装份数粗算）。

先把明显变质、不能确认可食的食物排除。营养再丰富，不安全也不能计入可用食物。

### 第一步：粗算能量能撑多久

有包装标签时：

1. 找到“每份”或“每 100 克”的能量；
2. 乘以实际剩余的份数或重量；
3. 把所有可用食物相加；
4. 再结合人数、平时实际食量和当前活动强度，估算能维持多久。

没有标签时，不追求一个看似精确的总数，先按用途分类：

| 类别 | 常见食物 | 判断作用 |
|---|---|---|
| 主食 | 米、面、谷物、薯类、面包 | 通常承担大部分日常能量 |
| 高能量补充 | 食用油、坚果、花生酱、芝麻酱 | 体积小、能量密度高 |
| 含糖食物 | 糖、蜂蜜、甜食 | 能快速补充能量，但不能替代其他类别 |

完成标准：能够说清“主要能量来自什么”“哪一类最先用完”“按当前消耗大致能撑多久”。如果只能说“还有很多吃的”，却不知道主食和油脂有多少，清点还没有完成。

### 第二步：检查四个位置

把一天或几天的可用食物放进四个位置：

1. **主食和其他能量来源**：米面、谷物、薯类等；
2. **蛋白质来源**：豆类、豆制品、蛋、奶、肉、鱼、坚果等；
3. **脂肪来源**：食用油、坚果、种子、花生酱以及食物本身的脂肪；
4. **提供不同维生素和矿物质的食物**：蔬菜、水果、豆类、蛋奶肉鱼、强化食品等。

不要求每一餐都把四个位置摆得一样，但连续多天只剩一个位置，就是需要处理的缺口。

盐不提供能量，也不能代替其他矿物质。日常优先使用来源可靠的食用盐；有碘盐时正常使用，不因担心短缺而把食物做得更咸。缺水时还要减少高盐食物，见 [[饮食与饮水]]。

### 第三步：先补最明显的缺口

| 发现的问题 | 优先动作 | 可用替代 |
|---|---|---|
| 主食很少，其他食物很多 | 先降低不必要的体力消耗，并寻找可持续的能量来源 | 薯类、面食、杂粮；短期用油脂和坚果补充能量 |
| 只有米面等主食 | 给现有餐食加入一种蛋白质来源和少量脂肪 | 豆类、豆制品、蛋、奶粉、罐头鱼肉、坚果 |
| 有豆类但燃料不足 | 提前浸泡、切小或改用更快熟的蛋和豆制品 | 罐头豆、豆腐、花生酱等可直接吃或容易加热的食物 |
| 油脂很少 | 保存现有油脂，按餐少量使用 | 坚果、种子、花生酱，以及安全可食的含脂肪食物 |
| 长期没有蔬菜水果 | 优先寻找耐储存或当季的不同类别食物 | 干菜、蔬菜水果罐头、豆类、强化食品 |
| 食物很多但种类单一 | 轮换搭配，不要把稀缺类别集中在一两餐吃完 | 少量分散到多天，与主食一起吃 |

替代时看它承担的作用，不要求找到完全相同的食物。没有肉，可以用豆类、蛋、奶或鱼补充蛋白质；没有新鲜蔬菜，也可以先利用状态正常的罐头、干菜和豆类增加多样性。

### 第四步：把判断交给分配和计划

* 当下怎样分给不同的人，见 [[食物分配]]；
* 缺水时怎样调整饮食，见 [[饮食与饮水]]；
* 怎样把现有品类补成可轮换的储备，见 [[长期食物计划]]；
* 长期从哪里种、养或获得食物，见 [[食物来源规划]]。

在清单上记录每一类预计用完的时间。最早用完的关键类别，就是下一次补充的优先目标。

## 判断是否需要调整

下面这些情况说明现有安排没有维持住人：

* 食物消耗速度明显快于清点时的估计；
* 连续一段时间只能吃单一主食，蛋白质或脂肪来源已经断掉；
* 体重持续下降，日常活动越来越难完成；
* 明明还有食物，却因为太硬、需要太多水或燃料而无法实际吃到；
* 有慢性病、伤病恢复、孕哺期、婴幼儿或吞咽困难等需求，却只能套用一般人的安排。

先重新清点实际能吃到的食物，而不是账面数量；再减少无效劳动、调整烹饪方式并补最明显的类别。最后一项不能靠本节点给出处方，应保留原有饮食要求并寻求相应医疗或照护建议。

## 注意

* **先保证食物安全。** 变质、来源不明或需要特殊去毒的食物，不能因为短缺而降低安全标准，见 [[食物安全]]、[[基础加工]]。
* **不要突然大幅缩减所有人的食物。** 先核对浪费、记录误差和活动安排，再决定怎样分配。
* **油脂耐放程度不同。** 已有哈喇味或状态异常的油、坚果不能用来补能量，判断见 [[变质判断]]。
* **补充剂不能替代食物结构。** 不清楚成分、剂量、禁忌和保存状态时，不把维生素或矿物质补充剂当作通用方案。
* **特殊人群不能直接套平均规则。** 婴幼儿、孕哺期人员、老人、病人和伤员可能需要不同质地、频率或营养安排，本节点只提醒单独识别，不提供处方。
* 短期吃得单调不等于立刻出现缺乏；风险在于缺口持续存在。记录“缺了什么、缺了多久”，比猜测某一种缺乏症更可靠。
