金属焊接

2026-09-19
Print

铁锹断了、桶裂了、水管脱了、锅漏了。没有电焊机，也照样能把两块金属连成一块——靠的是把它烧到近熔、撒上药、几下锤实。这一篇写「没有电焊的焊接」。

立即知道

  • 先想「能不能不焊」。铆、套、缠、胶，能用的地方比焊稳、比焊省事、比焊快——焊是最后手段。
  • 铁要焊上，得烧到白亮；暗红、樱红那是「红热」，差着几百摄氏度，怎么锤都合不上。
  • 铸铁不能锻焊，铝没法自己焊。这两样改走铆接和胶接。

一、三种自己能做的「焊」

按难度从低到高，能低不高。

1. 锡焊（软钎焊）—— 小件、薄件、不漏为主

要什么说明
烙铁铜头烙铁（铜块砸成斧头形，插木柄），在炭火上烧。至少备两把，轮着烧
焊锡现成锡丝、锡条最好；拆旧电器焊点、旧锡器也行
药松香（首选）、硼砂；焊水（氯化锌）腐蚀性强，用完必洗净

做法：

  1. 把要焊的两面刮到发亮（刀刮、砂纸、石头擦）——氧化层不刮掉，锡永远不上；
  2. 涂一层松香；
  3. 烙铁烧热（滴一滴锡上去能立刻化开、冒白烟就是够热），先烫热工件，再把锡丝往工件上送；
  4. 锡自己流开、铺成亮面 = 成了；锡堆成球、发灰发暗 = 虚焊，重刮重做，别在旧锡上再堆。

能焊：铜、黄铜、铁皮、水壶、盆罐、接线端子。 焊不了：铝、不锈钢（要专用药）、厚大件（烙铁热量不够）。

2. 铜钎焊（硬钎焊）—— 铁件、钢件的小缝和补裂

用黄铜丝 / 铜丝当焊料，硼砂当药。

  1. 接缝对好、磨出缝口，撒硼砂；
  2. 放进炭火或炉火里烧，烧到暗红到樱红（约 800~900℃）；
  3. 黄铜丝往缝上一贴，它在红热时自己化成水、被吸进缝里（这叫「虹吸」，不用硬抹）；
  4. 拿出来缓冷（埋灰，别丢水里）。

比锡焊牢得多，仍不如锻焊。适合：铁管接头、链条、薄壁容器补裂、铁件小面积接合。

3. 锻焊（火焊）—— 真正的「焊铁」

  1. 只对低碳软铁、锻铁。高碳钢（锉刀、弹簧钢）一烧就废，铸铁一烧就裂。
  2. 两件对好：搭接或对顶，先绑铁丝固定。
  3. 进炭火或焦炭火，鼓风烧。烧到白亮、表面像出汗一样起小泡——这时它已经到初熔，是唯一能焊上的一刻。
  4. 取出要快，立刻撒一层细沙或硼砂（把表面氧化皮顶掉，不撒就焊不牢）。
  5. 放铁砧上，三四下重锤快速砸实，趁热一气把缝打合。
  6. 没合上：重新烧、重新撒药、再打。一次烧不成就多来几次，别在凉铁上死砸。

温度看色：暗红约 550~650℃ / 樱红约 750~850℃ / 亮橙红约 900~1000℃ / 白亮约 1200℃ 以上（锻焊要这一档）。

二、多数情况该用「机械连接」

这些不用高温，往往更结实，也不会把铁退火变软。

  • 铆接（最推荐）：打通孔 → 穿一根铁钉（去掉钉头当铆钉）→ 一头垫在硬物上，另一头用锤把露出的部分墩成帽，把两件死死夹住。
  • 套接／夹箍：断轴外面套一段铁管或铁箍，两侧打孔穿销钉或螺栓锁死。断轴、断柄首选这个。
  • 缠绕：铁丝、铜丝在接缝上密绕十几圈后再拧紧。只用于受力不大的地方。
  • 螺栓：有现成螺栓就用；没有丝锥板牙就不必追。
  • 胶接：铸铁裂口、水管、油箱——化工 的皮胶、鱼鳔胶；铸铁裂缝最实用的是铆接 + 胶封两道一起上。

三、判断焊得牢不牢

  1. 看焊缝：饱满、发亮、没有黑灰气孔（黑灰 = 药没起效 / 温度不够，是虚焊）。
  2. 敲：小锤敲焊口周围，声音闷实不发空。
  3. 试：承重的吊重物、砸几下；装水的盛水放几个时辰看渗不渗。
  4. 看裂在哪：裂在焊缝旁边（不是焊口上） = 冷得太快、应力太大 → 重新烧到暗红、埋灰缓冷（回火）。

注意

  • 红热的铁看不出发亮，和黑铁一个颜色——锤子敲到哪、手扶在哪，先想清楚再上手。长钳上件，别用手扶。
  • 崩屑、火星：锤打、凿切崩铁屑，护好眼睛；周围别放干草、油布、柴堆。
  • 一氧化碳：炭火炉子绝不在屋里、棚里闷着烧，见 火与环境。
  • 镀锌铁皮（发青白亮的那种）不能直焊：加热会冒出有毒白烟。先在通风处把镀锌层刮掉、磨出铁本色再焊。
  • 不知装过什么的桶和罐，别烧：汽油、油漆、酒精的残留蒸气会爆。空桶也要先在露天敞开几天、灌满水再动火。
  • 动静就是暴露：敲铁声传得远、火光夜里几里外可见。固定一个偏僻点、短时做、避开清早和夜里。
