复杂机械修理

2026-09-19
Print

手压井不出水、缝纫机卡死、自行车蹬不动、手摇发电机不转。这类带轴、带齿、带弹簧的东西坏了，没有修理铺、没有备件，只能自己开箱。这一篇写「怎么把它转到能用」。

立即知道

  • 先判断值不值得修。机件缺一块、壳体裂穿、轴断在根部——修不如拆，把它拆成备件。
  • 九成的「坏」只有三个原因：脏、缺油、偏了。先按这三条查，别一上来就全拆散。
  • 一次只拆一个方向，拆前先做记号。装回去装不上，比不修更糟。

一、哪些能修，哪些别碰

值得修（结构看得懂）别碰（修不了，只能拆件）
手压井、手压泵、水泵压缩机、冰箱机头（密封件无处配）
自行车、板车、绞盘、滑轮组精密仪表（游丝、磁钢、玻璃）
缝纫机、手摇磨、脱粒机电器控制部分（电子件）
手摇发电机、风机、水车内燃机的油封、缸体、喷油件

判断标准：凡是「轴 + 齿轮 + 弹簧 + 皮碗」组成的，能修；凡是靠「精密配合 + 密封件 + 电子」的，别修。

二、四条诊断路（不拆也能查）

  1. 看：先擦干净外表，找漏（油渍、水痕）、锈、变形、被磨亮的金属面（磨亮处 = 那里在磨）。
  2. 听：手动空转，听声音从哪来——「咔」是齿，「吱」是缺油，「哐」是轴承松。
  3. 摸：慢慢转一整圈，手感觉哪一段发紧——发紧的那一段就是卡点，通常在那里 10~20 厘米范围。
  4. 记：拆之前，用凿子或铁钉在相邻两件上刻一条对线（不能用笔画——油会抹掉）；零件按拆下顺序在板上一字摆开，左边是开头、右边是末尾。

三、清洗与上油（最常见的「坏」）

  • 洗：拆下的件用煤油、柴油或热水加草木灰泡刷；齿缝里的泥用竹签、旧牙刷剔。工作面（齿面、轴面）绝不用砂纸磨，磨掉一层就永久松了。
  • 除锈：泡醋一晚，钢丝刷轻刷，洗净吹干；锈坑里的黑点不必挖。
  • 干透再上油：带水装回去必再锈。
  • 上油点：铜轴套、开式齿轮、棘爪、链条、弹簧、铰点；只薄薄一层——油多了粘灰，变成磨料糊。
  • 没有机油：动物油、熟油（见 化工）都能顶；动物油易酸败发粘，要常擦重涂。

四、按症状对症

症状先查怎么处理
转不动 / 卡死脏、锈、轴弯洗净除锈；轴弯垫木轻敲校直；转一圈找卡点，磨亮的高点用锉轻修
转起来晃、偏心轴与孔磨大轴孔加薄铜皮垫片；磨得厉害就截一段铜管做新铜套砸进去
皮带 / 绳打滑张紧不够、沾油调紧；皮带抹干撒松香粉（或磨糙、涂点动物脂+松香）；皮带伸长剪短重接（搭口钻孔用线缝或小铆钉）
有齿声、跳齿齿面崩、啮合偏崩一两个齿：把齿轮掉个面（用没磨损的那一侧）继续用；崩得多：镶齿或重做（见 金属加工）
弹簧、发条断—短一段重做：断口烧红压平、钻孔、铆接；弹性没了就烧红重新淬火回火，见 金属工具
泵不出水引水、进气、阀、皮碗见下
漏水、漏气皮碗干、垫片烂皮碗泡油回软；裂了照样剪新皮碗（旧皮鞋底、厚皮、橡胶胎）
电机不转碳刷、接线、轴承碳刷磨短了垫一段铜片顶住；轴承加油；线圈烧黑就别修了

泵不出水的检查顺序（照这个顺序走）

  1. 泵里没水 → 灌引水，灌到满再压；
  2. 灌了还不吸 → 吸水管漏气（接头、裂缝）→ 涂肥皂水找泡、缠布涂胶或换管；
  3. 压着有「嘶嘶」空响 → 底阀没关严（砂粒垫住或橡胶片烂）→ 提出清洗或剪新阀片；
  4. 出水断续、无力 → 皮碗磨损 → 换皮碗；
  5. 一切正常但水很小 → 出水管堵 → 通管。

五、没有备件怎么办

  • 拆东补西：同类坏机是最好的备件库——两台坏的拼一台好的。
  • 改件：旧皮带裁短、旧齿轮掉面、旧轴截短、旧铜管做套、旧轴承垫片。
  • 改用途：实在修不回来的，拆成铰链、配重、铁料、齿条、弹簧，见 金属回收。

六、判断修好没有

  1. 空转：手动转一整圈，顺、无卡点、无异响；
  2. 负载：接上真实负载跑，转速正常；
  3. 发热：连续跑半个时辰，摸轴和壳体不发烫（烫 = 缺油或偏心）；
  4. 复检：停一会儿再转，还顺才算成。

注意

  • 弹簧、发条、重物都带着力。拆之前一定先卸力：发条用铁丝扎住、重物落地、弹簧压住再卸销——回弹会打脸、打断手指。
  • 崩屑伤眼：开机构、敲轴、剪皮碗都可能崩金属屑，挡一块透明塑料或戴护目镜。
  • 别用明火烤机件：精密件受热变形，弹簧火烤就退火失弹。
  • 油布、煤油、擦洗布都是火源：别堆在屋里和火边，用完埋掉或烧掉。清洗味道传得远，也是暴露。
  • 敲打、锉磨有动静：需要低调时垫布、慢修、短时做，别在同一个时间天天敲。
  • 没有图纸可查：装得回去，全靠拆前刻的对线和摆开的零件顺序；拆的时候多花两分钟做记号，装的时候省两个时辰。
