# 安全用火

> 火不看住，会烧到住处和储备。点火前先隔开可燃物、备好灭火手段；人离开或睡觉，火必须灭。消防还叫得到，先撤人再报警；叫不到，就靠这几条。

## 立即知道

四条铁律：

1. **火不离人。** 点着的火必须有人看；人离开或睡觉，火必须熄灭。
2. **隔离可燃物。** 火的四周和上方留一圈净空，至少一米，地面无干草、纸、油布。
3. **密闭空间必须通风。** 任何明火都耗氧、产一氧化碳。
4. **先备好灭火手段再点火。** 水、沙、湿毯、锅盖，至少一样在手边。

### 一氧化碳：看不见的死因

一氧化碳无色无味，是密闭空间用火最主要的死因。危险源排序：煤炭 > 木炭 > 燃气热水器 > 明火柴堆。**炭火取暖是头号场景。**

判据按这个顺序看，**一个人住也成立**：

| 判据 | 怎么确认 |
|---|---|
| 多人同时发作 | 头晕、恶心、无力，几乎同一时间出现——感冒不会这样整齐 |
| 开窗缓解、关窗加重 | **最硬的一条**，一个人也能自己验证 |
| 独自一人时 | 突然头晕、恶心、腿软、反应变慢，而屋里的火正烧着——直接按中毒处理 |

**独处是最危险的情形**：没有第二个人的症状给你做对照，等"再观察一下"，往往就在这一觉里过去了。宁可误判开窗受冻，不要留下来观察。

处理只有一个动作：**立刻开窗、走出屋子、到外面呼吸新鲜空气。** 不要留在屋里"缓一缓"——中毒会让人昏睡，睡过去就不会自己醒。

报警器只能算加分项：**电池还在、还会响的时候，它能替你守夜**；电池耗尽、又买不到新的那天起，能靠的就只剩通风习惯和"不在密闭室内烧炭"这两条。

## 怎么做

### 点火前的位置检查

* 周围一米内无可燃物，上方无悬挂物；
* 地面是石面、金属盘或砖，不是地毯、木地板、干草地；
* 附近没有油瓶、酒精、喷雾罐；
* 逃生方向畅通——**火不在你和大门之间**。

### 紧急情况处置

| 情况 | 正确做法 | 绝对不要 |
|---|---|---|
| 油锅起火 | 关火、盖锅盖 | **泼水**（爆溅扩散） |
| 衣物着火 | 停、躺、滚 | 站着跑 |
| 酒精闪燃 | 湿毯覆盖 | 用水冲（酒精浮在水面继续烧） |
| 电气起火 | 先断电再灭火 | 带电泼水 |
| 怀疑一氧化碳 | 立刻开窗、走出屋子 | 留在室内"缓一缓" |

### 有儿童、宠物时

* 与火源之间做**物理隔离**，口头警告无效；
* 蜡烛放不易碰倒的浅盘里，远离窗帘被褥。

## 注意

* 报警器电池还在时挂上，人睡着后对中毒零感知；电池耗尽后，只能靠通风和不在室内烧炭。
* 不要用打火机在黑暗中查看燃气泄漏处，见 [[燃气安全]]。
* 灭火手段在点火**之前**备好，着起来再找就晚了。
* 室外、室内的场景深化见 [[室外用火安全]] 与 [[室内用火风险]]。
