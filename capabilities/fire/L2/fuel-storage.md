# 燃料储存

> 燃料储备本身就是火险。存得越多，越要当危险品管。消防还叫得到就报警；叫不到，隔离和灭火手段必须在点火之前就在手边。

## 立即知道

三个共同敌人：

| 敌人 | 后果 |
|---|---|
| 潮 | 木柴发霉难烧、引火物报废、炭吸潮 |
| 火 | 储存区起火 = 储备清零并引燃住处 |
| 散失 | 受潮、蒸发、被挪用——"以为有很多"其实不多 |

分类储法：

| 燃料 | 储法 |
|---|---|
| 木柴 | 架空离地、顶部遮盖、侧面通风、不贴墙 |
| 炭 | 干燥密封 |
| 液体燃料（酒精、煤油） | 原包装密封、直立、阴凉、远离一切火源 |
| 气罐 | 直立、阴凉通风、不进卧室和地下室 |
| 蜡烛、固体酒精 | 密封、避热 |
| 纸类引火物 | 密封袋防潮 |

## 怎么做

### 选位置

* 与居住区、火源保持距离；
* 不占逃生通道，不放电气箱下方；
* 阴凉、通风、地面干燥。

### 分散与限量

* **同一种燃料不集中在一处**——一次火灾、一次水浸不应清空全部储备；
* 液体燃料和气罐按"够用一段"存，不追求囤大——它们是活火险；
* 盘点时记录数量和位置。

### 定期检查

每隔一段时间检查：

* 包装有无鼓胀、锈蚀、渗漏；
* 气罐阀口有无油污损坏；
* 柴堆有无受潮霉变、虫蛀。

## 注意

* **液体燃料的蒸气比空气重**，沿地面流动，能飘到几米外的火源回燃——"离火三米"不算远。
* 气罐不倒放、不加热、不暴晒，见 [[燃气安全]]。
* 汽油不作为储备燃料：挥发快、极易爆燃，没有安全的家庭储存条件。
* 储存区不吸烟、不动火、不用电动工具。
