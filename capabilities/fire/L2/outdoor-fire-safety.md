# 室外用火安全

> 室外没有墙替你挡风挡火星。隔离带、灭火手段和看管都要自己做。消防还叫得到，跑火就先撤人再报警；叫不到，跑火和暴露的后果都要在点火前算进去。

## 立即知道

室外用火的三条风险轴：

| 风险 | 说明 |
|---|---|
| 跑火 | 火蔓延出预定范围——干草、落叶、风是三个放大器 |
| 暴露 | 烟、火光、气味在很远外就能被察觉——需要低调时必须管理 |
| 看不住 | 风向、材料、天气在使用中变化，火不按你的计划烧 |

与 L1 的分工：[[安全用火]] 讲任何火都适用的规则；这一节讲**室外特有的事**——场地、看管、离开、低调。

## 怎么做

### 建立火场

1. **圈定火界**：以火点为中心清到裸土或石面的环带，半径按当天风力放大；
2. **清空上方**：低垂树枝、晾晒物；
3. **下风方向检查**：下风的可燃物清走，火从下风蔓延最快；
4. **灭火手段就位**：水、沙、湿毯放伸手可及处；
5. 全部完成后才点火，顺序不能反。

### 看管

* **火不离人**，哪怕"就五分钟"；多人轮值，交接说出口；
* 大风天（树枝持续摇动以上）**停用明火**；
* 发现火苗越界，第一动作是**隔离**（打断燃料连续性），不是扑打。

### 低调用火

需要降低存在感时：

* **白天用火**——火光在夜间传得远，白天烟相对不显眼；
* **火要小**——小火爆燃、快烧快灭，比大火堆好；
* **用干柴、烧透**——湿柴闷烧烟最大；
* 选有遮蔽的地形（洼地、岩壁侧），避开高地和空旷处；
* 达科塔火洞（地洞火）能把火光压低到地面以下，见 [[简易炉具]]。

### 离开规程

* 浇透 → 翻搅 → 再浇 → 手背试温，见 [[火源熄灭]]；
* 灰烬摊开检查；
* 走出一段再回望一次，确认无烟。

## 注意

* 烧过的地面看着安全，**热灰踩穿同样烫伤**。
* 酒后、疲劳时不要负责看火。
* 火界是动态的：烧得越久，周边越干，圈要往外收。
* 大量山火源自"应该没事"的最后判断——熄火检查不是可选动作。
