# 选择安全位置

> 位置决定庇护的上限——再好的搭建也救不了一个选错的地方。

## 立即知道

选位置要躲开的危险，按"看不见但致命 > 看得见"排序：

| 危险 | 特征 | 为什么危险 |
|---|---|---|
| 河床、干涸河道 | 上游可能正在下雨 | 洪水沿河道突然到来，头号杀手 |
| 低洼地、沟底 | 冷空气和水都往低处积 | 夜间积水、湿冷加倍 |
| 崖壁、陡坡下方 | 上方有碎石、土体松动 | 落石与塌方，无预警 |
| 孤立高树下、空旷高地 | 位置显眼突出 | 雷击、强风倒树 |
| 枯树、悬挂断枝下方 | 树冠或枝干已死 | 无风也可能掉落 |
| 蚁穴、蜂巢、兽径附近 | 观察地面与树干痕迹 | 动物威胁，夜间尤其 |
| 城市危险建筑旁 | 墙体裂缝、玻璃幕墙 | 余震与大风时坠落 |

## 怎么做

### 四步选位

1. **看天**：判断主要威胁是雨、风、冷还是热，威胁不同选法不同。云、风和水位有没有变，见 [[环境观察]]、[[危险信号]]；
2. **看水往哪流**：找地势略高、地面能自然排水的地方；雨后地面有积水痕迹就是排水不良；
3. **看上方和上方之外**：头顶有没有会掉的东西，坡的上方有没有会滑下来的东西；
4. **看向背**：冷天和风天找背风面（建筑、山体、密林的背侧）；热天反而要通风。

### 城市里的优先顺序

1. 自己家（结构完好时）——熟悉的资源、门锁、补给都在；
2. 建筑内部的高楼层大空间（避开顶层与外墙）；
3. 建筑内部远离外墙与窗户的小房间；
4. 只有整栋建筑不安全时才离开——**移动本身常常比待着更危险**。

## 注意

* **"看起来方便"的位置往往危险**：路口、桥下、河边看起来资源多，但也是水、风、人流、坠物的通道。
* 地面本身也要查：湿软地面失温快，白蚁巢和腐木地不承重。
* 选定后先躺下来试 10 分钟——很多问题（风声、湿气、坡度）躺着才发现。
* 进入任何建筑前，先看裂缝走向、门框是否变形、有没有滴水声，见 [[危险识别]]。
* 洪水、落石和雷雨的下一步不在这里展开：信号见 [[危险信号]]，到了触发线见 [[撤离判断]]，雷雨时人怎么做见 [[电气危险]]，已经在涨水边见 [[水域安全]]。地形本身怎么读，见 [[地图与地形]]。
* **位置本身就是暴露**——需要低调时，避开路口、制高点、显眼地标和灯火能照到的地方，选有遮蔽、从外面不易察觉的角落。庇护失败大多不是"搭得不好"而是"选错地方"，位置决定生死。
