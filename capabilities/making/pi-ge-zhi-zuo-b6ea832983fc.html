皮革制作

2026-09-19
Print

手里已经有一张鞣好的革（怎么做出来见 制革）。这一篇写「怎么把它变成脚上的鞋、背上的包、腿上的护具、装水的水袋」。

立即知道

  • 皮件没有缝纫机，靠的是锥子打孔 + 双针走线。
  • 线必须过蜡：麻线拉过一块蜡，才能不吸水、不磨断、不松散。
  • 湿皮好裁好成型，干皮好留形。整套手艺就是在这两态之间来回。

一、先备六样

要什么代用办法
锥子一根粗钢针钉在木柄上（菱锥最好用，圆针也行）；见 金属加工
针粗钢针；没有就磨骨针（兽骨削尖打孔）
线麻线最结实；其次筋线（兽筋晒干撕成细条）、细皮条
蜡蜂蜡、松脂、动物脂——见 化工
裁刀锋利的刀或剪，见 刀
垫板一块木板，打孔时垫在下面

再加：一块湿布（回软皮子）、一根木棒（磨边压光）、几块石头或木模（成型用）。

二、通用手法

  1. 裁：皮略回软时最好裁（喷点水、湿布闷一会儿）。用木条压直、沿边划开，一次划到底，别来回蹭（来回蹭会起毛边）。同一张皮上尽量顺应纹路、朝一个方向裁。
  2. 打孔：垫木板，锥子垂直穿透。孔距要一致——先用指甲在皮边压出等距印痕再打。常用孔距 5~8 毫米。
  3. 过蜡：麻线拉过蜡块，来回捋两三遍，直到线身发亮发硬。线长取缝距的 3~4 倍，太短接不上、太长打结。
  4. 缝（双针马鞍缝，最牢）：
    • 线两头各穿一根针；
    • 第一针从第一个孔穿过，两根针分别向两侧、每一孔都是两根针交叉对穿；
    • 一根松的时候另一根拉紧，缝出来咬死不放。断了也不会整条散开。
    • 图省事可以用单线来回缝，但结实程度差一截。
  5. 收边：边角用刀削斜（削边）→ 用木棒蘸水反复擦热压光 → 涂蜡。摸上去不割手才算完。
  6. 湿成型（做鞋、套、袋的关键）：把皮泡软 → 裹在模具上（石头、木模、自己的脚、装满沙的口袋）→ 拉紧绷平 → 阴干定形。干了以后皮就记住这个形状。

三、做几样最实用的

束口软底鞋（一双皮的简单鞋）

  1. 量脚：脚踩在皮上画轮廓，四周各留出两指宽；
  2. 剪下一块（要做底就剪两块，叠起来缝）；
  3. 泡软，脚踩上去，把四周的边往上折包住脚背；
  4. 沿边缘一圈打孔，用皮条或麻绳穿过，抽紧束口（像系口袋一样），在脚背处打结；
  5. 脱下来阴干定形。干后再穿上，绳松了随时收紧。
  6. 磨底：底面再缝一两层厚皮，或钉一层木底。走山路最好在底面钉几颗钉当防滑。

护腿 / 护臂

一块皮裹住小腿或前臂 → 两边打孔 → 绳带交叉穿过绑紧 → 上缘往外翻一圈防磨。砍柴、割草、搬运最实用的一件。

袋 / 背包

方形裁片对折 → 两侧走双针缝 → 口部打一圈孔穿皮绳束口 → 背包再加两条宽皮条做肩带，受力处加铆钉（铁钉穿过去、两头弯脚砸平，见 金属加工）。

水袋

  1. 两三块皮缝成一个袋，缝口一律朝外翻（针脚不接触内壁的水）；
  2. 缝线处里外都涂蜡 + 松脂糊（化工 的混合膏），趁热抹进针眼；
  3. 最防水的做法是在袋里加一层动物膀胱或肠衣做内胆，再收口扎紧；
  4. 认命的一点：皮水袋只能装水搬运，不能长期存水——泡久了皮发软发臭，用完要晾干。

皮带、背带、绳

整条皮裁成长条 → 削圆两边 → 涂蜡即可。宽皮条也能当缰绳、捆带。

风箱皮、鼓面、马具

  • 风箱皮：皮加木框做鼓风的皮囊（金属冶炼 要用，见 炉火）；
  • 鼓面/垫子：湿皮绷紧钉在框上，干后自然绷响；
  • 马具、挽具：皮条 + 铆钉 + 铁环，受力处双线加铆。

四、判断成没成

  • 线：双手用力拉，缝口不松不张嘴，没有空着的孔；
  • 边：涂过蜡、压过光，摸上去不刮手；
  • 用：沾水泡过再晾干，不发硬不开裂（说明皮鞣透了，见 制革）；如果洗一次水就硬得像板，那是鞣制没做透，回 制革 补做；
  • 最先坏的地方：受力角度处的线。发现起毛就补针，别等到穿了。

注意

  • 别把皮长时间泡在水里：泡久了会泡掉鞣料、发臭，等于白做了鞣制那道工。湿过之后一定阴干、别暴晒。
  • 干皮别硬折：会顺着折痕裂开。要折先回软。
  • 锥子扎手是常事：左手戴厚皮手套或垫一块皮，锥子朝外推、别对着掌心；针用完插在蜡块上，别丢在草里。
  • 涂油防水：做好的皮件定期涂一层动物脂或熟油，能防水、防干裂（见 化工）。
  • 鞋要多备一双：脚上那双烂了就再没有第二双，提前做。
  • 别浪费碎皮：碎皮熬皮胶（见 化工），小条做绑带，都比丢掉强。
  • 气味与锤声是暴露：鞣皮、涂脂有气味，做鞋、铆钉有敲打声；在固定偏僻处做、别在住处正风口，见 火与环境。
