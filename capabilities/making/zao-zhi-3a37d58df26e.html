造纸

2026-09-19
Print

没纸也能记事——刻木、结绳、竹简都行。但纸能写字、能包东西、能滤水、能糊窗，是「能被卷起来带走的信息」。这一篇写「怎么把破布烂绳打成一张纸」。

立即知道

  • 纸 = 纤维 + 水 + 一张捞网。把纤维打散成浆，用网捞起来一层，压干、晾干，就是纸。
  • 原料越干净省事，纸越好。 破布、旧麻绳、旧纸最省力；树皮、稻草、竹子要煮很久。
  • 洗干净是成败关键。煮料用的碱水不冲干净，纸会脆、会黄、会招虫。

一、三条原料路线（挑省力的走）

路线原料省力度
回抄旧纸旧纸、旧书、纸箱、报纸最省力，撕碎泡软直接打浆
布麻类破棉布、麻绳、旧衣、烂渔网次省力，最结实，纸韧性最好
皮秆类构树/楮树/桑树内皮、竹、稻草、玉米秆最费工，但要多少有多少

操作：

  • 布麻类：剪成指甲大小的碎块 → 泡半天 → 加草木灰水或石灰水（见 石灰与草木灰）煮 1~2 小时，煮到纤维手一扯就散 → 用清水反复漂洗到水清。
  • 皮秆类：剥下树的内皮（外层粗皮不要）/ 把竹、稻草捣裂 → 同样用碱水煮到纤维能轻松撕散（往往要煮几小时，泡几天更好）→ 洗净。
  • 旧纸回抄：撕碎泡软就行，不用煮，直接打浆。

二、打浆（决定纸的均匀度）

目标：把纤维打到一根根分散、不再成股。

  • 工具：石板加木槌捶；或把料放木盆里用刀反复剁细；量少用手搓也行。
  • 判断到位：抓一小撮放进清水里抖一抖，纤维像棉絮一样散开飘动、没有硬结块，就是好了。
  • 打不够 → 纸上有疙瘩、厚薄不均；打过头 → 纤维太短，纸脆。
  • 加「纸药」（可选但很有用）：把黄蜀葵根、猕猴桃藤、杨桃藤这类植物的黏液（捶出黏滑汁液）加进浆里，纤维就不会沉底结块，捞出来更匀。没有也能做，只是要边捞边搅。

三、捞纸（工具与手法）

要什么代用办法
抄纸帘木框绷细竹篾 / 马尾 / 旧纱窗网 / 细密布，绷紧钉死
槽木盆、水缸、大木槽，能容下帘子平放
浆浓度一盆水加一到两把浆，搅成「米汤」的稠度

手法：

  1. 帘子斜着插下水，再端平往上提；
  2. 提起后前后左右轻轻晃一下（让纤维互相交织、分布均匀）——这一步是纸匀不匀的关键；
  3. 侧着控水，等到不再滴水；
  4. 翻扣到一块湿布或木板上（帘子轻提揭开，纸就留在布上）；
  5. 一层纸一层布叠成一摞，上面压木板加石头榨水，压到不出水为止。

四、干燥与「施胶」

  • 阴干，别暴晒（会翘、会裂）。想快就把湿纸贴在木板或墙面上晾，干后自己会脱开。
  • 施胶（想用毛笔写字、想耐磨就做）：趁纸半干，用米汤或糯米浆水薄刷一遍（见 化工），干后再用；也可用明矾水。
  • 想更白：把纸或纸浆摊开日晒夜露几周（民间叫「日光漂白」），煮料时用过石灰的也会自然白一些。
  • 想更光：干后用光滑石头或木棒在上面碾磨压光。

五、判断成没成

  • 成：整张揭下来不破，透光看纤维分布均匀，对折再展开不发脆开裂；
  • 败：一碰就烂（浆太稀或纤维太短）、有疙瘩（没打散）、发黄发臭招虫（没洗净碱水）。

六、更省力的记录载体（纸不够时先用这些）

  • 树皮布：构树/楮树内皮泡软后反复捶打成整张薄片，能搓不能写，做衣服和包东西极好；
  • 桦树皮：内层滑，能划字、能引火；
  • 竹简、木牍：刨平写字，耐存不怕潮，比纸重；
  • 白布刷浆：布上刷米汤或石灰浆，当纸用；
  • 刻木、结绳：数目和账目直接用刻痕，见 长期储存系统——不值得写下来的东西，别浪费纸。

注意

  • 煮料的碱水烧手烧眼（石灰水、草木灰水都强碱）：戴护手、别俯身对着锅边、溅到眼睛立刻大量清水冲。
  • 煮料要烧很多火：燃料消耗大、烟也大，在室外下风口煮，别在屋里闷烧（一氧化碳），见 火与环境、木炭制作。
  • 抄纸怕风也怕冻：水面一层浆会被风吹皱；浆结冰就毁了。选背风处、避开结冰天。
  • 纸最怕潮、虫、火：存纸要离地、夹层隔开、放干燥避光处；别对折——折痕先烂，卷起来存最好。
  • 废浆水和洗料水别倒进饮用水源（碱水、腐料会污染），倒在下游远处。
