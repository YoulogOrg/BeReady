# 制作的基本逻辑

> 没人给你送碗、送篮、送衣时，能用的器物要从身边的木、藤、泥、纤维里做出来。商店还在，先分清哪些值得自己做、哪些直接买。

## 先做能用的，再做好用的

* 先求一件器物解决一个活：盛水、盛食、盛物、遮、垫、绑。
* 能凑合就用，别等「完美」——等，就是一直没得用。
* 用上了再改：补、加、换料，一轮轮变好用。

## 一件器物一材多用

* 选料先想它能干几件事：木碗也能当量杯、当灯座；木盘也能当盖、当托盘。
* 少做只干一件事的器物，多做一个顶两三个的。

## 就地取材优先

* 取料顺序：木 → 藤/竹 → 泥 → 纤维 → 骨 → 石。软的先上，硬的留到要结构时。
* 身边有什么做什么，别惦记店里买不到的东西。
* 同一处取料别取光：留根、留母藤，下次还有。

## 注意

* 做器物会留痕迹（刨花、碎泥、灰）。需要低调时，收走或埋掉废料，别在显眼处堆。
* 湿料做的器物干透才结实，没干透别承重、别装水。
* 取材与初加工归下一步的 [[材料]] 能力；原料来源见预告 [[木材]]、[[黏土与石料]]、[[纤维材料]]。
