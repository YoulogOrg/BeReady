安全

Print

在环境、资源和社会秩序发生变化时，识别危险、降低风险并保护自己和他人的能力。

安全与其他能力不同。

水、食物、火等主要解决“没有什么”的问题；安全首先解决：

什么事情不能做，以及怎样避免让情况变得更糟。

安全能力贯穿所有其他能力。

Level 总表

Level名称一句话目标节点数
L1 · 避免直接危险识别明显危险，在危险发生前避让9
L2 · 风险判断在不确定中比较风险，优先做降低风险的行动8
L3 · 应对事故危险已发生时控制事态、减少伤害、脱离危险8
L4 · 长期安全建立可持续的个人与小群体安全机制9

判据：L1 当天就能用、不依赖材料与工具；L2 需要经验与判断积累；L3 需要在压力下执行规程；L4 需要长期规划与群体协作。

L1 · 避免直接危险

能力目标

能够识别明显危险，并在危险发生前采取最基本的避让措施。

不够怎么办

  • 环境不确定、风险叠加 → 进入 L2 的 风险与收益、信息不足时的判断。
  • 危险已经发生 → 进入 L3 的 事故现场安全。
  • 场景性危险已有专章：用火见 火 的 安全用火，燃气见 燃气安全，水域同时见 水。

核心知识

  • 危险识别
  • 安全距离
  • 危险区域
  • 建筑物基本安全
  • 火灾安全
  • 水域安全
  • 高处安全
  • 电气危险
  • 有毒环境

L2 · 风险判断

能力目标

面对不确定环境时，能够比较不同选择的风险，并优先采取降低风险的行动。

不够怎么办

  • 事故已经发生 → 进入 L3。
  • 需要长期机制 → 进入 L4。

核心知识

  • 风险与收益
  • 信息不足时的判断
  • 撤离判断
  • 安全路线
  • 环境观察
  • 危险信号
  • 群体行动安全
  • 夜间安全

L3 · 应对事故

能力目标

危险已经发生时，能够控制事态，减少进一步伤害，并帮助自己和身边的人脱离危险。

不够怎么办

  • 医疗处置超出事故现场能力 → 转入 急救 能力（专业急救与伤情管理）。
  • 事态不可控 → 回到 L2 的 撤离判断，以撤离为先。

核心知识

  • 事故现场安全
  • 撤离
  • 求救
  • 基础急救
  • 火灾应对
  • 建筑坍塌风险
  • 危险物质暴露
  • 伤者转移

L4 · 长期安全

能力目标

在正常社会秩序长期无法恢复的情况下，建立能够持续运行的个人与小群体安全机制。

不够怎么办

  • 安全能力的长期内容应重点放在：降低风险、避免冲突、保护人员和资源，而不是追求对抗本身。

核心知识

  • 安全区域
  • 风险监测
  • 资源安全
  • 夜间防护
  • 基本规则
  • 团队分工
  • 冲突避免
  • 安全撤离
  • 长期风险管理
