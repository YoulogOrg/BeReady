# 环境观察

> 警报和广播还在，拿它们当外源。没有的时候，靠固定观察建立基线，变化就是异常。

## 立即知道

观察不是"到处看"，是**"固定点、固定时间、反复看同一批东西"**。

先记下"正常长什么样"，之后任何偏离基线的变化，都当预警。

## 观察表（每天同一时间，10 分钟走完）

| 看什么 | 怎么记 | 什么时候算变了 |
|---|---|---|
| 水位 | 岸边固定石头/树上的刻痕 | 一夜涨过**一掌宽** = 上游有情况 |
| 风向风力 | 看烟、看草叶倒向 | 风向突然改，火和气味都会改道 |
| 天气 | 云形、耳朵/关节的压迫感 | 云底发黑压得低、风停得反常 = 要来 |
| 动物 | 鸟、虫、蛙的动静 | 突然全静 = 附近有动静，先去弄清是什么 |
| 声音 | 水声、机器声、人声、树倒声 | 出现新的、持续的异响 |
| 气味 | 烟、焦、化学、腐臭 | 任何新气味都要记 |

**要在固定位置做标记**：岸边绑一块石头、树上刻一道线——不这么做，你根本判断不出"涨了还是落了"。

## 怎么做

* 选 3 个固定观察点：驻地高处（看远）、水源（看水）、常走的路口（看来路）；
* 每天**同一时间、同一路线、同一顺序**走一遍；
* 记"变化"而不是记"现象"：今天和昨天比，什么不一样了；
* 优先盯与自己有关的：来路、退路、水源、燃料、危险源方向。

## 怎么记（没有纸笔）

* **刻痕木牌**：一件事一道，用不同位置区分类型；
* **结绳**：每种颜色/位置代表一类，多一个结就是"有变化"；
* **石子分罐**：几个罐子代表几个观察点，发现异常投一颗；
* **关键是能比对**——不能比对的记录等于没记。

## 注意

* 动物是免费的预警系统：鸟群突然安静或惊飞、蚂蚁搬家、狗反常——都值得警惕；
* **顺风闻气味、逆风听声音**——下风向闻得到，上风向听得到；
* 夜间观察靠听和闻，不靠看（视线不可靠），见 [[夜间安全]]；
* 观察的本钱是"之前看过"——没建立基线，异常也看不出来。**从第一天就开始记，坚持记**；
* **你自己也会形成规律**：固定时间、固定路线本身是暴露。观察点要选不显眼的位置，偶尔换时间，见 [[安全路线]]。
