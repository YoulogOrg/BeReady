# 通信的基本逻辑

> 消息只能靠你亲手传、亲手收——没有电话网、没有基站、没有互联网，别指望有人替你转达。

## 信息靠什么传

* **无线电** —— 有设备时最快，能听也能说，见 [[无线电基础]]。
* **光 / 烟 / 声音** —— 看得见听得见就传得远，见 [[信号与标记]]。
* **人力** —— 自己人或信使跑腿，最稳但最慢，见 [[人力传递与约定]]。
* **约定** —— 提前说好的暗号、会合点、时间点，让信息「对得上」。

## 信息贵在「对得上」

* 没有约定的信号，对方看不懂；先约定，再使用。
* 约定只在自己人之间成立：暗号、标记、会合点，见 [[群体行动安全]]。
* 一条信息写清：是谁、在哪、要做什么、何时。

## 不暴露

* 信号、烟、火光、声音都会暴露你的位置和人数。
* 需要低调时收着用：短说、少发、发完换位，见 [[火与环境]]。
* 传什么、传给谁，先想清楚再动手。
