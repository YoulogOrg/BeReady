简易无线电制作

2026-10-01
Print

设备坏了、没电池了，还有一条路：自己做一个不用电池的收音机。它靠天线收到的电波直接推动耳机，声音小，但能听见，而且永远不担心没电。

立即知道

  • 先做收（矿石收音机）：不要电、元件少、最靠得住；
  • 发很难自制到有用的距离（几十到一两百米），而且长时间发射最暴露——力气花在收上。

一、矿石收音机的四件东西

部件用什么
天线10–20m 长线，架到树顶、杆顶、屋顶；越高越好
地线铁杆或铁板打进潮湿泥土 30cm 以上，接一个夹子；土干就浇点盐水
调谐线圈漆包线 / 裸铜线在纸筒、竹筒或塑料管（直径 5–10cm）上密绕 60–100 匝
检波 + 耳机锗二极管（废收音机、旧电器里的小玻璃管，如 1N34、2AP 一类）+ 高阻耳机

耳机必须是高阻的：2000Ω 以上的老式电话听筒、舌簧耳机、压电陶瓷耳塞都行；普通 32Ω 耳塞接上去几乎听不见声音。

二、怎么接（照做）

  1. 天线接线圈的一端；
  2. 线圈的另一端接二极管，二极管另一头接耳机，耳机另一头接地线（二极管两头对调试一次，反了声音更小就换回来）；
  3. 选台：在线圈上刮出一段裸铜，用鳄鱼夹或一段裸铜丝在线圈上滑动接触——滑到哪匝听哪匝，声音最大的那个点就是台。

有可变电容的话（废收音机里拆的 365pF 那种）把它并在线圈两端，转它选台，比滑动接触细得多。

匝数与台的关系：匝数多收低频台，匝数少收高频台；60–100 匝配 365pF 覆盖中波广播段。

三、找不到二极管怎么办

  1. 拆：旧收音机、充电器、遥控器、节能灯板里的小玻璃管或黑壳小管，多半能用；
  2. 做矿石检波器：找一块亮灰色金属光泽的矿石（方铅矿最好，黄铁矿也行），嵌在金属小碗或锡纸里，用一根细钢针（针尖弯成小弯钩）轻触矿石表面，慢慢挪动找「有声音的那一点」，找到后用胶或蜡固定住；
  3. 矿石检波声音更小、更挑点，要有耐心——这是最原始的做法，能成。

四、调试顺序（不响就按这个查）

现象先查
一点声音都没有地线没接好 / 太干 → 重打地线、浇水
只有极小的沙沙声天线太短太低 → 加长、再架高
有声音但听不清耳机阻抗太低 → 换高阻耳机
时响时不响接头氧化 → 所有接头刮亮、拧紧
换了位置就没声天线碰树、碰墙、被雨淋湿

顺序永远是：地线 → 天线 → 耳机 → 接头 → 二极管。 天线和地线比什么都有用，加长、架高、埋深，比换元件管用。

五、用它干什么

  • 听广播：还有发射台在播，就能收到本地强台，内容交叉验证，见 获取与判断信息；
  • 判局势：能收到哪个方向传来的发射，说明那边还有人在用无线电；收不到的时段和方向，也是信息；
  • 外放（有电时）：把耳机两端接到坏音响、收录机的输入端，就能放大出声。

六、自己做发射（先明白限度）

  • 极简振荡电路（一个三极管或 555 加几米天线）能发几十到一两百米，只够自家院子到相邻院落；
  • 更实用的做法不是自己发，而是把现有对讲机的天线架高、加外接天线，效果远好于自制发射机，见 长距离通信；
  • 真要发，就短、少、低：短时间、少内容、小功率。

注意

  • 天线、地线、接头全部刮亮拧紧——接头氧化是矿石机不响的头号原因。
  • 天线远离电线和金属；雷雨天把天线从设备上断开并接地，见 电气危险。
  • 白天和夜里能收到的台不一样，换个时段再试，见 长距离通信 的时段一节。
  • 这个设备不接发射时只收不发，不会暴露位置；但天线架得太高太显眼仍是暴露，需要低调时收下来。
  • 湿手别碰天线接线端；架天线别一个人爬高，见 高处安全。
