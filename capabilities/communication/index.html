通信

2026-10-01
Print

电话和网络还在，用它们把消息送到该到的人。它们断了，就要自己把信息传出去、收回来，用来判断局势、跟自己人协调。

通信的前提是「没网没电也能用」。本能力只写信息传递与获取：怎么跟同伴联络、怎么标路线标位置、怎么听外界动静、怎么靠人跑腿。信号、烟、火光、声音都会暴露位置，需要低调时收着用。

Level 划分

Level能力目标核心知识
L1 · 立即可用当天就能用，手头现有物品（镜/金属/哨/火/收音机对讲机），不需要额外制作3
L2 · 需要条件/经验需要一定设备、约定经验或观察判断：听广播辨局势、人力传递与暗号2
L3 · 进阶超出对讲机距离的联络；无电池的自制收音与发射2

判据：L1 当天就能用、靠现成物；L2 需要设备/约定/判断力；L3 需要天线与架设、长距中继的组织。

L1 · 立即可用

能力目标

没网没电的当天，用手边现有物品跟同伴联络、标记路线和位置、用无线电听和说。信息贵在「对得上、不暴露」。

核心知识

  • 通信的基本逻辑
  • 信号与标记
  • 无线电基础

不够怎么办

  • 现成信号传不远、看不清局势 → 进入 L2（获取与判断信息）。
  • 没设备、信号用不了、需要异地协调 → 进入 L2（人力传递与约定）。
  • 同伴分散、需要稳定长距联络 → L3 的 长距离通信。

L2 · 需要条件/经验

能力目标

靠收音机短波听外界、靠观察环境判断局势、靠信使和暗号跟分散的同伴交换信息——消息要交叉验证，别轻信单一来源。

核心知识

  • 获取与判断信息
  • 人力传递与约定

不够怎么办

  • 普通无线电距离不够、需要更远联络 → L3 的 长距离通信。
  • 没有设备、想自己造简易电台 → L3 的 简易无线电制作。

L3 · 进阶

能力目标

把通信半径拉出对讲机的范围：靠架高的天线、选对时段与地形、靠人接力，把消息送到几公里之外；设备没了，还能用废料做一台不用电池的收音机。

核心知识

  • 长距离通信
  • 简易无线电制作

不够怎么办

  • 需要电力与蓄电保障 → 转 能源 的 电池与蓄电、太阳能发电。
  • 需要人跑腿、约定暗号 → L2 的 人力传递与约定。
  • L1 / L2 / L3 已全部建成，本能力暂无更高层方向。

相关能力

  • 安全 —— 通信会暴露位置，低调用法见 火与环境、室外用火安全；判断局势见 环境观察、信息不足时的判断。
  • 导航 —— 标记路线、不迷路、信使认路见 行进与定位、不迷路的习惯。
  • 能源 —— 无线电省电、续航见 电池与蓄电、照明。
  • 火 —— 火光与烟信号的点火与熄灭见 基本点火、火源熄灭、室外用火安全。
  • 撤离 / 安全路线 —— 会合点、信使路径与转移协调。
