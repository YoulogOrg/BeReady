生产

2026-10-01
Print

储备会吃完，外面也采不长久。超市、饲料和兽药还在，就按需要补；补不上时，能一直有饭吃的，是自己种、自己养、自己加工出来的那一口。

生产是把「找食物」变成「产食物」的能力。本能力只做三件事：动物养殖、食物加工、种养结合的长期规划。植物种植归 种植，野外食物的基础处理（识别、清洗、焯水）归 基础加工，这里不重造。

Level 划分

Level能力目标核心知识
L1 · 立即可用当天就能想明白盘子怎么摆，动手做最稳的那一环1
L2 · 需要一定条件/长期养得活、加工得出、盐熬得出、一个季度到一年排得开4
L3 · 长期与批量把畜群当两本账来选留与配种；饲料账、批次、工时一起放大2

判据：L1 是布局与取舍，不依赖额外物资；L2 需要场地、时间、耐心和持续工时；L3 需要代际管理（几年的选留记录）与扩群扩产（饲料账 + 批次循环）。

L1 · 立即可用

能力目标

看清自己处在「找食物」还是「产食物」阶段，把种、养、加工三环摆好位置，先动手做最稳的那一环，不贪大。

核心知识

  • 生产的基本逻辑

不够怎么办

  • 想动手养 → 进入 L2（基础养殖）。
  • 产出多了存不下、吃不完 → 进入 L2（食物加工）。
  • 想把一个季度到一年的盘子排开 → 进入 L2（食物来源规划）。

L2 · 需要一定条件/长期

能力目标

养活至少一种能自我繁殖的肉/蛋/奶来源；把种和养的产出加工成能跨过荒季的存粮；按季节把种什么、养什么、存多少、吃多少、留多少种排成可执行的盘子。

核心知识

  • 基础养殖
  • 食物加工
  • 制盐
  • 食物来源规划

不够怎么办

  • 需要稳定遗传、越养越顺手 → L3 的 育种选育。
  • 需要成规模产出、一年有结余 → L3 的 规模化生产。

L3 · 长期与批量

能力目标

把「养得活几只」变成「一直有得吃」：会挑会配，畜群一代比一代顺；饲料账、批次循环、人手工时同步放大，让产出一茬接一茬、荒季不断档。

核心知识

  • 育种选育
  • 规模化生产

不够怎么办

  • 地里那侧的扩种、多块地错开、轮作 → 转 种植 的 种植规模扩大。
  • 植物留种与选株 → 转 种植 的 育种选种。
  • 产出要长期存住 → 转 储存 的 长期储存系统、无电冷藏。
  • L1 / L2 / L3 已全部建成，本能力暂无更高层方向。
