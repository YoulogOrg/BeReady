化工

Print

皮、骨、鱼鳔、糯米、树皮、松脂能熬成胶、涂料和清洁用的料，用来修器物、做弓、糊纸、封缝。商店里买得到就买；买不到，就用这些材料自己做。

先划清：这些别重复做

以下已经有专门节点，本节点不再写：

  • 碱（草木灰、石灰）→ 石灰与草木灰；肥皂 → 制肥皂。
  • 盐 → 制盐。
  • 食用油、榨油 → 食物加工。
  • 蜡、松脂火把、油灯 → 简易油灯与蜡烛。
  • 防腐熏烟、木炭 → 火用于食物加工、木炭制作。

本节点只写三类空白：胶（粘合）、涂护料（防水防腐）、酸。

一、自制胶（粘合）

皮胶 / 骨胶（最常用，什么都能粘）

  1. 原料：兽皮下脚料（见 制革）、蹄、角、骨头。
  2. 洗净去脂——脂肪不刮净，熬出来发臭、粘不牢。
  3. 放锅里加水没过，小火慢熬几个时辰，熬到汤发稠、挂勺能拉丝。
  4. 滤掉渣，小火收浓到冷却后能凝成胶冻。
  5. 用法：趁热涂、趁热合（凉了就凝住），压紧晾干。要拆开时浇热水就松——这也是它的好处。
  6. 存：切成小块晾干放着，能存很久；用前加水泡软、加热化开。

鱼鳔胶（最牢、比皮胶耐水）

  • 鱼鳔洗净去膜，用木棒砸软，加水久熬成稠胶。
  • 粘木器、做弓最牢，耐水性比皮胶好。做精细件值得留着用。

糯米浆 / 米浆胶（不用熬料，最省事）

  • 米或碎米煮成很稠的浆（或把米加水磨成浆后熬稠），趁热涂、趁热合。
  • 粘纸、糊窗、贴布最好用；怕潮，别用在长期受水的地方。
  • 加一手：糯米浆掺进石灰浆里砌砖石，比纯石灰浆牢得多，见 石灰与草木灰、永久建筑。

树皮浆糊（应急，随手可得）

  • 捣烂榆树、构树的内皮，加水揉出黏液，直接涂（见 纤维材料）。
  • 粘性一般，修簸箕、糊条缝够用。

二、涂护料（防水、防腐）

  • 松脂：松树伤口流出的黏汁，直接涂在木器、绳头、竹管接缝上防潮。怕热，别靠火，见 基础修理。
  • 熟油：油料榨出后加温熬过再涂（生油干得极慢），涂在木、布、纸上，干后结成一层膜。涂一遍、干一遍，涂两三遍才算够。涂完要晾很久才干透。
  • 混合膏：动物脂 + 松脂 + 木炭粉，一起熬化搅匀。填缝、涂绳、抹皮子，防水又有韧性。
  • 这些是器物的涂护；墙体和屋顶的防水另有一套，见 防水结构、防水。

三、自制酸

  • 这里的酸不是用来造东西的，最实用的是除锈、去垢、鞣皮辅助。
  • 最省事的一路：让食物发酵过头——果渣、果皮加水（有糖更好），敞口放几天，发酸发刺鼻就滤出清液，越酸越好用（见 食物加工 的发酵）。
  • 用途：泡锈铁件（泡一夜，捞出刷洗）、擦水垢、去油污，见 清洁与消毒。
  • 绝不能做：别内服、别洗伤口、别装在金属容器里存（腐蚀容器、溶出金属）。

通用工序（三类都靠它）

  • 熬：小火、勤搅，别糊底——糊一锅废一锅。
  • 滤：粗布、细沙、干草层都能当滤材。
  • 收浓：小火蒸发水分。判断：挂勺成丝、滴在冷石上能凝就是够了。
  • 试：第一次小量做，拿边角料试粘、试涂，成了再上正式件。

判断成没成

  • 胶：冷却能凝成块；涂后压一夜粘住，掰开时木屑撕开、而不是胶面脱开 = 真粘住了。
  • 涂料：干后不粘手、泼点水不渗 = 成了；永远发黏不干 = 熬得不够或掺了油。
  • 酸：闻着刺鼻、泡铁件一晚锈能刷掉 = 浓度够。

注意

  • 熬胶、熬油都是浓烟加焦味，极明显的暴露源：下风、远离住处、短时做，见 火与环境。
  • 熬油易燃：锅别装太满、别添猛火，旁边备湿布或干土压火。
  • 酸、石灰都伤手伤眼，见 石灰与草木灰、清洁与消毒。
  • 别乱配捡来的化工品：不认识的桶罐可能装过农药、溶剂，别开封，见 金属回收。
  • 所有产出先小量、先试再上——料坏了不伤人，急着上大件才伤人。
