# 制肥皂

> 肥皂是最缺、又最救命的清洁品——没有它，手洗不净、油污去不掉，脏病顺着脏手进嘴。肥皂=碱+油脂，碱从草木灰来，油脂从动物油或废油来，都能自己做。

## 立即知道

* 肥皂 = 碱液 + 油脂，小火熬到稠、凝固即成。
* 碱液 = 烧透的草木灰泡水、滤清。灰里的碱能洗掉油。
* 不用做成固体也能用：碱液直接兑水，就能洗手、洗衣、去油。

## 怎么做

### 第一步：取碱液

1. 烧木柴或干草，收集**烧透的白灰**（带黑炭渣的灰碱少，尽量要白的）。
2. 灰倒进桶或盆，加清水，灰和水约 1:2，搅匀。
3. 泡一天，让灰里的碱溶进水里。
4. 用布过滤掉灰渣，滤出的清液就是碱液。
5. 判断够不够浓：手蘸水有**滑腻感**（像肥皂水），滴在油污上能把油推开——够浓了；不够就再泡浓。

### 第二步：熬软皂（碱液 + 油脂）

> 草木灰的碱是「钾碱」，做出来是**软皂**（膏状、半凝固），不是商店里那种硬块——照样能洗手、洗衣、去油，不用非得结成硬块。

1. 碱液倒进**铁锅或不锈钢锅**——**别用铝锅**，碱会腐蚀铝、锅会漏。
2. 加油脂：熬出来的动物油（猪油、牛油、宰杀后的废油），或榨出的植物油。用量凭手感：约 1 份油配 3～4 份浓碱液，宁碱勿油（碱多洗得净，油多不起泡）。
3. 小火慢熬，**不停搅**，熬到变稠、像浓粥、舀起能拉丝。
4. 撒一点盐进去（盐能让皂更快析出），搅匀。
5. 倒进容器——木盒、竹筒、抹了油的盆都行，摊平。
6. 晾凉成膏状就能用；想再干一点就多晾几天让它失水变稠，装进能密封的容器。

### 简化版（连软皂都不熬）

* 直接用碱液：兑水搓手、搓衣、擦油污，一样能去油。
* 碱液现加一点油搅开，去污力更强，当天就能用。

## 判断成没成

* 成的软皂：膏状或半凝固、沾水能搓出泡、能把油污洗掉。
* 稀得不成膏、洗不掉油：油太多，回锅再加碱液重熬一次。

## 注意

* **碱液烧手、烧眼**：熬的时候别溅到身上，溅进眼立刻用大量清水冲；做完用清水把手冲净。
* 熬肥皂的火光和油烟显眼，位置和时段按 [[火与环境]] 处理。
* 草木灰潮了碱味就淡，取碱前先把灰存干，见 [[石灰与草木灰]]。

## 不够怎么办

* 没有油脂：别做固体，直接用碱液兑水搓洗，去油一样管用。
* 没有草木灰：烧贝壳或石灰石取石灰，泡水得石灰水。石灰水是**环境消毒**用的（刷厕所、撒地面、处理尸体），**别拿来洗手洗身**——烧手，也搓不出皂，见 [[石灰与草木灰]]。
