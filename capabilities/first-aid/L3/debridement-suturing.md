# 清创与缝合

伤口里有脏东西、烂肉、异物，不清理就会化脓。医院还去得了，清创和缝合交给能做的人；去不了，先判断自己能不能做，不能做的不要硬缝。

## 立即知道

* **清创** = 去掉死肉和脏物，是防感染最关键的一步，越早越好；
* **缝合** = 把能对合的伤口拉上；但脏伤口缝了反而糟，不如留开放引流。

清创有窗口：**伤后 6～8 小时内做效果最好**，超过 12 小时基本不要缝了。

## 清创的做法

1. **先止痛**：没有麻药，就用冰块隔布敷伤口周围 10 分钟，能麻掉一部分痛觉；大的清创，别一个人硬做，按住的人手要够；
2. **冲洗**：凉白开或淡盐水**大量**冲，压力大一点更好（用注射器或扎孔的水袋射水），一边冲一边把脏东西带出来；
3. **去异物**：消毒过的镊子夹出；
4. **剪坏死**：只剪**确定已经死了**的，活的别碰。四个判断：
   * 颜色：黑、灰、土黄；
   * 质地：烂、糊、跟周围分不出层；
   * 气味：臭；
   * 出血：剪开不出血 = 已经死了；
5. **再冲一遍**，直到伤口看起来鲜、干净；
6. **器械消毒**：镊子、剪子用沸水煮 **20 分钟**，或烧到发红后冷却再用。布、线同样煮过。

## 能不能缝（判断表）

| 情况 | 结论 |
|---|---|
| 干净、边缘整齐、6～8 小时内、能对合 | **能缝** |
| 超过 12 小时 | 不缝，留开放 |
| 脏伤口、有坏死组织 | 不缝 |
| 深而窄的刺伤 | 不缝（里面引流不出来） |
| 动物咬伤 | 不缝 |
| 化脓中 | 不缝，先引流 |

**没把握就不缝**——开放伤口勤换药也能长，缝错了化脓更难办。

## 缝合怎么做

* **线**：煮过的丝线、棉线都行；应急可用头发、植物纤维（都要煮过）；
* **针**：弯针好使，直的也能用（用钳子夹住推）；
* **间距**：每针间隔约 **0.5 厘米**，距伤口边缘也约 0.5 厘米；
* **深度**：要**穿过皮下**，只缝表皮会撕开；
* **打结**：打三重结，剪线时留 **1 厘米**的线头；
* **别缝太密太紧**——留一点缝让渗液出来，紧了对合处会缺血坏死；
* **缝合后**：盖上敷料，每天看，见 [[伤情长期护理与换药]]。

## 什么时候拆线

| 部位 | 天数 |
|---|---|
| 脸、脖子 | 3～5 天 |
| 头皮、躯干 | 7～10 天 |
| 四肢 | 10～12 天 |
| 关节处 | 12～14 天 |

拆早了会裂开，拆晚了线会长进肉里。**宁可晚一两天。**

## 注意

* 缝合是侵入操作，工具和线**必须**消毒，这是最不能省的一步；
* 缝合后头几天最怕感染，每天观察红肿热痛；
* 出现红肿流脓 → 立即拆掉一部分线放引流，见 [[伤口感染与恶化]]；
* 深部伤口、腹部贯通伤、大血管附近的伤，**别自己动手**——做不了的判断，比硬做强。
