伤情评估与优先级

2026-09-17
Print

先判断谁最要命、先处理什么——顺序错了，可能白忙一场还搭上命。

立即知道

按「要命程度」排序：气道 → 大出血 → 休克 → 其他。先处理会立刻死人的，再处理能等的。

评估不是诊断，是排顺序。一分钟之内做完，做完就动手，别站在旁边想。

一分钟扫查（按这个顺序）

  1. 喊一声：拍肩呼喊。睁眼、应声、能动 → 意识大致清楚；没反应 → 一律按最危重处理。
  2. 看呼吸（数 10 秒）：看胸腹起伏、听口鼻声、脸贴近感觉气流。
    • 正常成人 12～20 次/分；
    • >30 次或**<8 次**、或者只有倒气样的抽吸 → 最优先；
    • 完全没动静 → 立刻 气道与呼吸。
  3. 摸脉搏（数 15 秒 ×4）：颈动脉（喉结旁两指）或桡动脉（腕内侧拇指侧）。
    • 正常 60～100 次/分，手指下感觉得到力；
    • >120 次、细弱摸不清 → 休克正在发生，见 休克。
  4. 找血：从头到脚扫一遍，看衣服深色湿处、地面血迹。喷溅、持续涌出的最优先，见 止血。
  5. 看瞳孔：两边不一样大、或者对光不缩 → 脑受伤的征象。
  6. 摸一遍（顺序别乱）：
    • 头（凹陷、出血）→ 颈（不能转、一按就痛 → 按脊柱伤处理）→ 胸（按痛、呼吸时一边不动）→ 腹（发硬、一按就躲）→ 骨盆（两边向内挤有剧痛）→ 四肢（变形、反常活动、远端发凉）→ 背。

只有一个伤员：照这个顺序做

  1. 没呼吸 → 气道与呼吸（人工呼吸 + 胸外按压）；
  2. 大出血 → 止血；
  3. 休克 → 休克；
  4. 其次 → 烧伤见 烧伤处理，骨折见 骨折与脱位，伤口见 伤口处理与包扎。

不止一个伤员：先分堆，别先救最惨的

标记状态处理次序
红有呼吸但气道堵 / 大出血 / 呼吸极快极慢 / 叫不醒立刻，1 小时内
黄能呼吸、意识清，但重伤（骨折、腹部伤、大面积烧伤）几小时内
绿能自己走、能说话的轻伤可以等，能搭手就让他搭手
黑没有呼吸、没有脉搏、瞳孔散大固定放最后

黑标不是"放弃"，是"现在没空"——先把红的救回来，回头再看他还有没有机会。

注意

  • 一次只处理一个最要命的，处理完再评估下一个；
  • 别把时间耗在已经没有呼吸很久的人身上——资源有限，救得回的优先；
  • 判断不出来的时候，按更严重的那一档处理。宁可多绑一次夹板，不可漏掉一个内出血；
  • 饿着、累着、夜里做的判断会变差；重要的取舍，能等天亮就等。
