# 建造的基本逻辑

> 动手前先想清这个结构要围什么、存什么、挡什么。用途没想清，材料再够也立不住。

## 先想清用途再动手

* 围什么：圈动物、护菜地、挡风、还是隔出地块——用途决定形状和大小。
* 存什么：食物、工具、燃料，还是活物——存什么决定要不要防潮、防鼠、通风。
* 挡什么：风、雨、动物，还是只是划分地界——挡什么决定用桩、用墙、还是用网。
* 没想清就别动。搭错了拆比建还累，还浪费本来就少的材料。

## 结构靠承重和支撑

* 力往下走：每根桩、每面墙都得把重量传到地面，不能悬空靠绑。
* 支点要稳：桩要打进土、石要坐实，松土上直接垒会慢慢歪倒。
* 斜撑保直：高过人、受风的结构，加斜撑才不晃；光靠竖直桩一推就倒。
* 宁粗勿细：受力件用粗木、用整石，细枝只填空当，不扛重。具体搭法见 [[简易建筑]]。

## 量力而行，从简开始

* 先搭最小能用的，住一阵看哪里漏风、哪里塌，再补。
* 不一次想盖大盖全。材料有限，先保一头、再扩。
* 坏了就修，别等全烂。见 [[结构检查与修复]]、[[简单修补]]。

## 选址低调不显眼

* 选背坡、靠灌木、避开阔地的位置，结构轮廓融进环境，别立在高处当标记。
* 外形不求整齐气派，歪斜的棚比方正的屋更难被注意到。
* 动土的痕迹、踩出的路都会暴露，干完把土松散盖回、把常走路线分散。
* 烟、光、气味传得远，搭建和后续使用都控制这些，见 [[火]] 的 [[安全用火]]。

## 注意

* 结构倒了不是丢脸，是伤人——受力件松了先撑住再修，别在歪桩下站人。
* 不写「防谁」，只讲降低自己的可见度；结构和选址都只为少暴露、少麻烦。
* 需要住人的结构，回到 [[庇护]]；本能力只盖功能性的大结构。
