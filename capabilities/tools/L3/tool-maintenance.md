# 工具维护

> 刀和斧钝了、松了、锈了，活就干不利索，也更容易伤手。每天几分钟保养，比等它坏了再找替换省事；买不到新的时候，这一步决定还能不能接着用。

## 立即知道

维护和修理不是一回事：

* **维护＝让它别坏**（每天擦干、上油、检查）——本篇讲这个；
* **修理＝坏了怎么救**（柄松了、裂了、绳断了）——归 [[工具修理]]。

维护只做四件事：**擦干、上油、查柄与绳、放对地方**。

## 一、防锈（头号任务）

铁见水就锈，汗也是水。

1. **用完立刻擦干**——尤其刀身、斧刃、锯条；袖口、衣角都能擦；
2. **上油**——动物油、植物油、蜂蜡、凡士林都行，薄薄一层抹开。每天都用的抹薄油；**长期不用的厚涂一层**，再用布或油纸包起来；
3. **绝不湿着收**：湿布包着放、插在潮土里、放在没干透的鞘里，是最快的锈法（鞘也要晾干再用）；
4. **已经锈了**：先用细沙、草木灰或炉灰擦；锈得厚就用**醋泡**（见 [[化工]] 的酸），泡完立刻洗净擦干上油——放着不管，锈会一直吃下去。

## 二、刃口（每天用就每天顾）

* **每天用的刀**：每天在皮带、硬布或细石上荡几下，保持锋利——钝刀比快刀更危险，更费力、更容易打滑；
* **几周磨一次**：正经磨见 [[磨刀]]；
* **别拿来干的事**：砍钉子、铁丝、骨头、冻硬的肉、刨土、当撬棍、当螺丝刀——崩刃之后很难磨回来；
* **判断**：能顺畅推过一张纸、切湿布不打滑，就算够用；一旦切起来「打滑、压不下去」就该荡刃或磨了。

## 三、柄、楔、绳（每次用前看一眼）

* 甩两下、提起来晃一下：**头会动就先用 [[工具修理]] 收拾它**，别接着砍；
* 看柄有没有**新裂缝**，尤其柄头和接缝处；
* 绳的检查：看有没有起毛、断股、变硬发脆，见 [[绳索]]；
* 木柄**怕火烤、怕暴晒**：别放灶边烘干，一烤就裂。

## 四、放对地方

* **刃具**：进鞘、进木盒、挂上墙（刃口朝里或朝下）；别插在地上、别支在门口、别和别的工具堆一起（互相磕出豁口）；
* **绳**：卷起来挂起来，别摊在潮地上（会烂、会霉）；
* **木器与木柄**：阴凉干燥处，离火、离雨；
* **整批工具**：**别全放一处**——一次火、一次水就全没了；常用的随身、备用的分开藏。

## 五、多久查一次（照做）

| 周期 | 做什么 |
|---|---|
| 每次用完 | 擦干、上薄油、归位 |
| 每周 | 查柄松不松、裂没裂；查绳起没起毛；刃口荡一下 |
| 潮湿季（雨季、梅雨、化雪天） | 上油加勤，隔两三天查一遍有没有起锈点 |
| 长期不用 | 厚油 + 布或油纸包裹 + 干燥处，隔几个月拿出来看一次 |

## 六、什么时候放弃（别硬撑）

* 刃口**崩得太深**，磨不出直口了；
* 柄**裂到根**、换柄也固定不住；
* 弹簧钢件**失去弹性**（掰了不回弹）——当撬棍还行，当刀具不行；
* 放弃前先拆：**好的部分留下来**——木柄当柴或改小工具，钢片留给 [[金属工具]] 改制。

## 注意

* **打磨、敲打有声音**，需要低调时改手压慢磨；工具摆在明处也是暴露，见 [[工具的基本逻辑]]。
* 磨刃时**刃口永远朝外、朝离开身体的方向**推；磨完擦净铁屑再上油。
* 上油别用**已经酸败发粘的油**——它会自己招锈、招灰；油变味了就换。
* 非城市场景：野外没有润滑油，**动物油是最常用的替代**（熬出的肥油留一小罐专门擦工具）；雨天在外，工具用布包好放进背篓里，别露着淋。
