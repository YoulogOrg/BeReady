工具

2026-10-01
Print

用坏一件少一件。一把刀、一根绳、一根硬木，就是砍柴、搭棚、取水、分食、挖坑干得成干不成的分水岭。

工具是体力的放大器：同样的活，有工具省力一半，没工具累垮自己也干不快。本能力只写「怎么用工具把活干成」，绳索的打法、结构的搭法归别的章节，这里只引用，不重造。

Level 划分

Level能力目标核心知识
L1 · 立即可用当天就能用、手头现成工具（刀/斧/锯/绳/铲/撬），不需要额外材料5
L2 · 现场制作需要一定材料或制作步骤：磨刀、自制绳、简易木工具3
L3 · 长期与批量金属工具、工具维护、批量工具制作3

判据：L1 当天就能用、不需要额外材料；L2 需要一定材料与制作；L3 需要长期管理与批量产出。

L1 · 立即可用

能力目标

用身上和手边现成的工具，把砍柴、搭棚、取水、分食、挖坑、撬动这些生存动作真正干得动、干得快。

核心知识

  • 工具的基本逻辑
  • 刀
  • 斧与锯
  • 绳索
  • 挖掘与撬动

不够怎么办

  • 工具钝了、卷刃了，干不动也危险 → 进入 L2（磨刀）。
  • 绳用完了、断了 → 进入 L2（自制绳索）。
  • 没有现成工具，只有木料和废料 → 进入 L2（简易工具制作）。

L2 · 现场制作

能力目标

靠磨石、树皮、藤蔓、布条和硬木，把钝工具救回来、把绳造出来、把专用木工具做出来——让工具不断供。

核心知识

  • 磨刀
  • 自制绳索
  • 简易工具制作

不够怎么办

  • 金属件严重损耗、需要更稳定耐用的工具 → L3 的 金属工具。
  • 工具长期频繁使用需要保养、防锈、更换易损件 → L3 的 工具维护。
  • 同行家人多、需要多套工具并行、要能互换零件 → L3 的 批量工具制作。

L3 · 长期与批量

从「手边有什么用什么」进入「稳定供给工具」。

能力目标

从废墟废铁里挑钢、改造出耐用的刃与撬具；把工具当消耗品管起来——每天维护、按统一规格批量做、坏了随手换。

核心知识

  • 金属工具
  • 工具维护
  • 批量工具制作

不够怎么办

  • L1 / L2 / L3 已全部建成，本能力暂无更高层方向。
  • 需要从矿石出铁料 → 转 材料 的 金属冶炼；需要把钢做成器物（非工具类）→ 转 制作 的 金属加工。

相关能力

  • 庇护 —— 搭棚、支撑、绑扎靠工具；绳结见 绳结、木材连接见 木材连接、结构见 基本结构、支撑见 简单支撑、修补见 简单修补。
  • 火 —— 砍柴劈柴锯木见 斧与锯，存炭见 木炭制作，燃料见 木材燃料。
  • 水 —— 挖坑取水、撬盖、容器改造；储水见 安全储水。
  • 食物 —— 屠宰分切、加工、脱水见 食物脱水、储存见 食物储存。
  • 卫生 —— 挖坑掩埋粪便见 粪便处理、旱厕。
  • 医疗 —— 刀具也是切割包扎材料的工具，见 伤口处理与包扎。
