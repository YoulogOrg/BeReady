- 输出**崩溃基调**的简洁实用内容，杜绝和平时期科普。

## 九、跨章边界定案（避免重复建节点）

> 从 `.workbuddy/memory/MEMORY.md` 迁入此处集中维护（2026-09-19），MEMORY.md 只留指针。**新增边界先记这里，再考虑是否要进 MEMORY.md。**

- **一贯原则**：原料初加工归 [[材料]]，做成器物归 [[制作]]，修旧归 [[修理]]，成墙成屋归 [[建造]]。
- **消毒三处**：水的 [[消毒]] = 饮水；医疗 [[外用药与消毒]] = 伤口皮肤；卫生 [[清洁与消毒]] = 器具 / 表面 / 环境。
- **兽皮三段**：猎获屠宰归 [[食物]] → 出革料（[[制革]]）归 [[材料]] → 缝制皮具（[[皮革制作]]）归 [[制作]]。
- **维护 ↔ 修理**：[[工具维护]]（让它别坏，tools/L3）↔ [[工具修理]]（坏了修，repair/L2）。
- **修 ↔ 造（按动作性质划线）**：[[金属焊接]]（把断的接回去，repair/L3）↔ [[金属加工]]（把料做成器物，making/L3）。
- **金属器 ↔ 刃具工具**：[[金属加工]] 只做非刃具金属器（钉 / 箍 / 锅 / 管 / 铰链）；刃具与工具的「挑钢→退火→成型→淬火→回火」整套热处理归 tools/L3 [[金属工具]]。
- **做工具三件**：[[简易工具制作]] = 现场单件应急；[[金属工具]] = 改废钢管热处理；[[批量工具制作]] = 定规格成批做可互换。
- **种植 ↔ 生产（按对象划线）**：植物留种选株归 [[种植]] 的 [[育种选种]]；动物选留配种归 [[生产]] 的 [[育种选育]]。
- **住人 ↔ 功能结构**：住人结构归 [[庇护]]；功能性大结构（围墙 / 畜栏 / 仓库 / 道路排水）归 [[建造]]。
- **分工缩写**：食物卫生归 [[食物安全]]；伤口消毒归 [[外用药与消毒]]；绳结与木材连接归 [[庇护]]；动物养殖 + 食物加工 + 规划归 [[生产]]。
