# BeReady 内容路线图

> 本文记录对现有知识体系的缺口评估和候选工作，不是已经确认的目录结构，也不是创建节点的自动授权。
>
> 使用状态：
>
> - 本文现有条目默认属于**待研究**；
> - 经人工确认后，才能进入**已确认需要补充**；
> - 新增、拆分、合并节点或调整 `_nav`、`_book`，仍按结构规范先提案；
> - 已完成或决定暂不处理的条目，应在后续整理时明确标记，不从历史中直接删除。

**几个关键能力链还没有闭合**。

我把现有 19 章重新按“一个普通人真正要活下去，会遇到什么问题”走了一遍。现有框架已经覆盖了 **生存 → 稳定 → 自给 → 长期发展** 的主干，但有一些非常关键的“中间环节”缺失。

我会优先补下面这些，而不是继续无限增加知识点。

## 一、我认为最应该补的节点

### 1. 食物：缺一个「烹饪与热量管理」

现在有：

* 基本烹饪
* 食物安全
* 食物分配
* 长期食物计划

但“食物”实际上缺一个很重要的中间层：

* [[烹饪方法]]
* [[食物的热量与营养]]
* [[蛋白质来源]]
* [[脂肪来源]]
* [[盐与矿物质]]
* [[婴幼儿与特殊人群饮食]]

尤其是**热量与营养**，它连接“有东西吃”和“真正能够长期维持身体状态”。

---

### 2. 水：缺「水源寻找」之后的完整判断链

现在已经有：

> 寻找可用水源 → 水源基本判断 → 沉淀 → 过滤 → 消毒 → 煮沸

但还缺一些非常实际的节点：

* [[水源污染判断]]
* [[不同污染物的处理方法]]
* [[饮用水与生活用水分级]]
* [[缺水时的脱水判断]]
* [[人体每日用水需求]]
* [[取水与运输]]

特别是：

**“这个水能不能喝？”和“怎么把它变成能喝的水？”其实应该分成两个问题。**

---

### 3. 庇护：缺「环境与气候」

现在的庇护主要是建筑本身：

> 防雨、防风、保暖、防晒、通风、保温……

但用户真正选择庇护地点时，还需要：

* [[天气与气候判断]]
* [[地形与庇护位置]]
* [[洪水风险]]
* [[滑坡与落石风险]]
* [[雷电安全]]
* [[极端高温]]
* [[极端低温]]
* [[野生动物风险]]

其中 **洪水 / 山洪 / 雷电 / 极端天气** 我认为优先级很高。

---

## 二、安全这一章其实还缺一块很大的内容

现在“安全”已经有危险识别、撤离、求救、路线、夜间安全等。

但如果真的是长期环境恶化，最大的安全问题之一其实是：

### 「人与人」

建议增加：

* [[陌生人接触]]
* [[人员冲突]]
* [[群体安全]]
* [[资源冲突]]
* [[营地安全]]
* [[财物与资源保护]]
* [[安全边界]]
* [[信息保密]]
* [[可信任的人与组织]]
* [[交易与交换安全]]

这部分不用写成“末日战争指南”。

核心应该是：

> **怎样降低自己成为冲突对象的概率。**

我认为这会让 BeReady 和一般的“户外生存知识库”产生很明显的区别。

---

# 三、医疗目前明显偏薄

现在医疗只有：

* 常见药品及用途
* 药品储备
* 外用药与消毒
* 抗生素
* 剂量与禁忌
* 缺药
* 中草药
* 慢性病
* 自制酒精

这实际上更像“药品管理”，而不是完整的医疗体系。

建议补：

### 基础医疗

* [[体温、脉搏与呼吸]]
* [[血压与基本生命体征]]
* [[常见症状判断]]
* [[发热]]
* [[疼痛]]
* [[腹泻与呕吐]]
* [[脱水]]
* [[感染]]
* [[呼吸道疾病]]

### 长期医疗

* [[慢性病监测]]
* [[药物替代与减量]]
* [[长期用药储备]]
* [[牙齿与口腔护理]]
* [[眼睛与视力问题]]
* [[妇女健康]]
* [[儿童常见疾病]]

尤其是：

> **牙齿与口腔护理**

这个节点很容易被忽略，但长期脱离现代医疗体系以后，牙齿问题会变成非常现实的问题。

---

# 四、卫生应该增加「衣物」

现在卫生主要是：

> 洗手、粪便、垃圾、个人清洁、厕所、防虫防鼠……

但是长期生存中：

**衣服其实是身体环境的一部分。**

建议：

* [[衣物选择]]
* [[衣物清洗]]
* [[衣物晾晒]]
* [[衣物修补]]
* [[鞋袜与脚部护理]]
* [[保暖衣物]]
* [[防雨与防晒衣物]]

然后可以自然连接到：

> 纤维材料 → 织物 → 制作 → 缝补

这样整个知识体系会形成很好的横向连接。

---

# 五、工具还缺一个非常重要的「基础手工能力」

现在：

> 刀 → 斧锯 → 绳索 → 挖掘撬动 → 磨刀 → 自制绳索

比较合理。

但还缺：

* [[测量]]
* [[划线与标记]]
* [[切割]]
* [[钻孔]]
* [[打磨]]
* [[连接]]
* [[固定]]
* [[杠杆]]
* [[滑轮]]
* [[简单机械]]

这些其实是整个“制作 / 建造 / 修理”的共同基础。

甚至可以增加一个：

### [[工具的基本使用]]

让新手知道：

> 工具不是越多越好，而是先掌握少数工具解决多数问题。

---

# 六、能源现在缺「能源系统的基本逻辑」

现在是：

> 照明 → 电池 → 油灯蜡烛 → 机械能 → 太阳能 → 水力 → 储能

但缺少一层基础认知：

* [[能源的基本逻辑]]
* [[功率与能量]]
* [[直流电与交流电]]
* [[电压与电流]]
* [[电池的基本原理]]
* [[电线与连接]]
* [[用电安全]]
* [[电能分配]]

尤其 **用电安全** 不应该只藏在“安全”里面。

能源系统本身应该有自己的安全知识。

---

# 七、导航之外，其实缺一个「时间」

这是我比较意外发现的一个缺口。

长期生存体系里：

* 时间
* 日历
* 季节
* 天气
* 太阳位置

会越来越重要。

可以增加：

* [[时间判断]]

* [[季节判断]]
* [[历法]]
* [[天气观察]]
* [[季节性规划]]

它可以同时连接：

**导航 × 种植 × 越冬 × 食物 × 建造**

---

# 八、通信还缺一个「信息管理」

现在：

还缺：

* [[信息记录]]

这个非常重要，因为：

> **拥有资源 ≠ 能把资源搬到需要的地方。**

# 十、还缺一个非常重要的体系：物资管理

现在有“储存”，但储存解决的是：

> 东西怎么放。

而长期生存还需要：

> **我到底有什么？还能用多久？**

建议新增：

* [[物资清单]]
* [[物资分类]]
* [[物资消耗记录]]
* [[库存管理]]
* [[物资优先级]]
* [[物资寿命]]
* [[物资交换]]
* [[备用物资]]
* [[关键物资储备]]

这实际上应该贯穿：

**水、食物、药品、燃料、工具、种子、材料。**

甚至可以把“储存”改造成：

> **储存与物资管理**

# 十一、我还建议增加一个目前完全没有的领域：心理与生活秩序

这里不需要做成心理学。

而是非常朴素的：

* [[睡眠]]
* [[休息]]
* [[日常作息]]
* [[长期压力]]
* [[孤独与隔离]]
* [[长期生活秩序]]

因为 BeReady 的终点不是：

> “如何在荒野里多活一天”

> **建立自己的生活。**

到了这个阶段，生活质量本身就成为生存能力的一部分。

如果 BeReady 最终是一个真正的长期生存知识库，那么：

可以考虑：

* [[学习与训练]]

* [[技能传承]]

# 如果控制规模，我会优先补这 12 组

不是建议一次性把所有节点都加进去，而是我会按照重要程度分三档：

| 优先级      | 建议补充                           |
| -------- | ------------------------------ |
| **第一优先** | 水源污染判断、脱水、天气与气候、极端天气、人员冲突、营地安全 |
| **第一优先** | 基础生命体征、常见疾病、感染、脱水、口腔护理、用电安全    |
| **第一优先** | 物资清单、库存管理、物资消耗、物资优先级           |
| **第二优先** | 测量、划线、钻孔、连接、固定、简单机械            |
| **第二优先** | 衣物、鞋袜、清洗、修补                    |
| **第二优先** | 徒步负重、运输、长距离移动                  |
| **第二优先** | 信息记录、信息核实、紧急信号                 |
| **第二优先** | 时间、季节、天气观察                     |
| **第三优先** | 心理、长期生活秩序、娱乐                   |
| **第三优先** | 教育、技能训练、知识传承                   |

### 但我反而不建议现在继续大幅增加“生产技术”

因为你现在的：

> 材料 → 制作 → 建造 → 修理 → 能源 → 种植 → 生产

已经形成了很漂亮的 **“从生存到自给”技术链**。

真正的短板反而在前面：

> **判断 → 获取 → 处理 → 保存 → 管理 → 长期使用**

也就是说，目前不是“不会做东西”的问题，而是**生存基础设施还没有完全闭环**。

## 我会进一步做一个结构上的调整

如果让我继续整理这个 `_book`，我会考虑把现有 19 章背后抽象成这 8 条能力链：

**身体**
→ 急救 / 医疗 / 卫生 / 食物 / 水

**环境**
→ 安全 / 庇护 / 火 / 导航 / 天气

**资源**
→ 食物 / 水 / 储存 / 物资管理 / 能源

**工具**
→ 工具 / 材料 / 制作 / 修理

**居住**
→ 庇护 / 建造 / 卫生 / 能源

**生产**
→ 种植 / 养殖 / 加工 / 制造

**协作**
→ 通信 / 信息 / 人际安全 / 交易

**传承**
→ 学习 / 训练 / 记录 / 教育

这样一看就比较明显：**现在缺的不是“更多知识”，而是“物资管理、天气环境、人与人、行动运输、信息管理”这几个横向能力。**

而且这些恰好也是目前 `_nav` 中相对没有独立入口的部分；现有 `_nav` 主要还是围绕水、食物、火、庇护、安全、医疗、急救、卫生、工具、种植、导航、能源、储存、通信、修理、制作、建造、材料、生产以及场景/越冬展开。

我认为**下一步最值得做的不是马上把这些全部塞进 `_book`，而是先确定“哪些应该成为一级能力，哪些只是现有章节下的节点”**。这一层确定以后，整个 BeReady 的目录会稳定很多。
